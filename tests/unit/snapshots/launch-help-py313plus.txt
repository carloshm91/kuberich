                [--namespace NAMESPACE] [--all-namespaces] [--request-timeout REQUEST_TIMEOUT]
                [--log-file LOG_FILE] [--log-level LOG_LEVEL] [--refresh REFRESH_SECONDS]
                [--readonly] [--write] [--command INITIAL_COMMAND] [--headless] [--logoless]
                [--crumbsless] [--splashless] [--invert] [--screen-dump-dir SCREEN_DUMP_DIR]
                [--cluster CLUSTER] [--user USER] [--as AS_USER] [--as-group AS_GROUP]
                [--insecure-skip-tls-verify [INSECURE]]
                [--certificate-authority CERTIFICATE_AUTHORITY] [--client-key CLIENT_KEY]
                [--client-certificate CLIENT_CERTIFICATE] [--token TOKEN]
                {help,version,info,config} ...

A Kubernetes terminal UI built with Python and Textual.

positional arguments:
  {help,version,info,config}
    help                show launch help without loading configuration
    version             show installed version without loading configuration
    info                show safe local paths, preferences and installed versions
    config              initialize or validate local preferences

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --config CONFIG       Kubetrol preferences YAML (separate from kubeconfig)
  --kubeconfig KUBECONFIG
                        single kubeconfig file (otherwise KUBECONFIG or ~/.kube/config)
  --context CONTEXT     context to connect (otherwise current-context)
  --namespace, -n NAMESPACE
                        initial namespace (otherwise the context namespace)
  --all-namespaces, -A  select all namespaces for this session
  --request-timeout REQUEST_TIMEOUT
                        API/helper timeout: 0.1-3600 seconds, or ms/s/m/h (default 10s)
  --log-file, --logFile LOG_FILE
                        local diagnostic log path
  --log-level, --logLevel, -l LOG_LEVEL
                        DEBUG, INFO, WARNING, ERROR, or CRITICAL
  --refresh, -r REFRESH_SECONDS
                        periodic table refresh seconds (0.1-3600); watch changes remain live
  --readonly            block mutations, shell, attach and plugins
  --write               override the configured read-only preference for this session
  --command, -c INITIAL_COMMAND
                        initial terminal command: po, ctx, ns, status, retry, back, forward, help or
                        quit
  --headless            hide the application header
  --logoless            hide the brand in the header
  --crumbsless          hide the context/namespace scope bar

Recognized options awaiting their owning feature (exit 4):
  --splashless          unavailable: startup splash (U01 #56)
  --invert              unavailable: theme inversion (U01 #56)
  --screen-dump-dir SCREEN_DUMP_DIR
                        unavailable: screen exports (O06 #73)

Session connection overrides:
  --cluster CLUSTER     kubeconfig cluster alias for this invocation
  --user USER           kubeconfig auth-info alias for this invocation
  --as AS_USER          user/service account to impersonate; server permission required
  --as-group AS_GROUP   impersonation group; repeat to retain multiple groups
  --insecure-skip-tls-verify [INSECURE]
                        skip TLS verification explicitly; accepts =true or =false
  --certificate-authority CERTIFICATE_AUTHORITY
                        CA certificate file; enables TLS verification
  --client-key CLIENT_KEY
                        client private key file; requires --client-certificate
  --client-certificate CLIENT_CERTIFICATE
                        client certificate file; requires --client-key
  --token TOKEN         bearer token override; never included in diagnostics
