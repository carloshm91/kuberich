# Bordered command bar, contexts and container details

Focused preview issue [#129](https://github.com/carloshm91/kubetrol/issues/129)
implements a rectangular command row with retained inline completion, local
context workspace rows and captured container status/specification columns.
See [behavior and limitations](../resource-workspace.md) and the
[current trial](../first-preview.md).

Qualification is in progress; this document will record the frozen candidate,
actual matrix results, owned kind/PTY evidence and unavailable platform checks
before merge. No release or public artifact is published by this issue.
