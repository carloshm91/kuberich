## Process behavior

Pure tests verify immutable argv/environment/cwd/target snapshots, single and
merged explicit kubeconfig paths, context/namespace/container flags, shell/editor
argument boundaries, hostile literal values, bounded input and faithful exits.
The command builders do not interpolate shell strings. Resource-bound processes
require a current-target guard; read-only policy rejects every supported process
purpose before executable lookup, including direct service calls.

Forty-six local-process contract cases exercise real child processes: captured
stdout/stderr, relative PATH and cwd, actual nonzero/signal exits, exact/exceeded
output limits, timeouts, missing/failed executables, stale targets after spawn,
and foreground launch/claim failures. They cover delayed startup, repeated
cancellation, runner shutdown during startup, cancelled background waiters,
idempotent close, ignored termination, and a leader exiting while descendants
retain pipes. Final pipe overflow/errors after leader exit cannot report success;
delayed disconnect exercises transport closure. Children/transports remain owned
until cleanup completes. Failure messages omit argv, credentials and raw output.

## Native terminal behavior

Seven source PTY scenarios exercise the actual application, shared runner,
terminal lease and public Textual suspension:

- Success and nonzero child exit, with repeated handoffs.
- Actual Ctrl+C delivered to the child's foreground group.
- Owned worker cancellation while the child is using the terminal.
- Missing executable followed by a successful handoff.
- Parent SIGTERM, child cleanup and application exit 143.
- Read-only refusal before starting a child.

Synthetic owned programs verify foreground ownership and cooked input, receive
actual typed lines and terminal resize, deliberately change TTY attributes, and
then exit or are interrupted. After returning, a real keyboard probe verifies
the application's resized layout before a repeated handoff. Terminal restoration
is measured against the original attributes rather than inferred from output.

An additional fresh-installed wheel PTY uses these same production services
outside the source checkout, including repeated input/resize/return. This is an
installed API integration harness; it does not add or claim a CLI shell shortcut.

Initial qualification exposed a test synchronization assumption: interpreter
startup can precede the parent's foreground-group claim. The fixture now waits
through a real terminal read before checking ownership; kernel SIGTTIN/SIGCONT
participates in that handoff. The initial matrix and failed installed trial are
retained separately. All final full suites above pass on the same frozen trees.

## Reproduce and retained evidence

explicit CPython 3.12.12, 3.13.12 and 3.14.3. The full behavioral command is:

```sh
uv run --locked --python 3.12.12 pytest --cov=kubetrol --cov-branch --cov-report=term-missing --cov-report=xml --cov-report=json
```
