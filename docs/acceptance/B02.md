## Acceptance behavior

- UID keyed row/cell patches retain selection, a top-row scroll anchor and
  horizontal position. Tests instrument updates to assert no event-driven clear
  or recreation of unchanged rows. Deleted selections choose a deterministic
  neighbor; a recreated name has a new UID and preserves a surviving selection.
- Pure examples cover readiness, numeric restart counts, age/skew/unknowns,
  multi-container waiting/exit/signal outcomes, initialization order, restartable
  sidecar readiness/failure and ephemeral exclusion. Sorting uses typed values,
  deterministic ties and unknown ages last in both directions.
- Pilot qualifies paging, header/keyboard sorts, quiet age updates, escaped
  Unicode/control fields and 40×12 data space. Owned HTTP watches drive modified,
  deleted and recreated rows. Chunked patches yield and reject obsolete revisions;
  a deliberately blocked decoder cannot stop namespace input or publish old rows.
- Real CLI PTYs cover streamed cells, paging/sorting, namespace changes and
  resize, followed by terminal attributes, cursor, screen and reporting restoration.
  Built distributions also show actual rows from an owned API outside the checkout.
- A uniquely created kind 0.33.0 / Kubernetes 1.36.4 cluster checks pod readiness,
  status and integer restarts against the server Table, then runs the actual widget
  through retained selection/sorting and empty namespace switching. Prior API/TLS,
  paginated snapshot, LIST/WATCH-gap, UID recreation, quiet-renewal and cleanup
  checks also pass. Only fixtures inside this owned cluster are mutated and the
  cluster is deleted afterwards.
