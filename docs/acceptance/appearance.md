# U01 #56 acceptance evidence

The next-release source registers validated opaque custom themes and built-ins,
previews without writes and saves global/context preferences explicitly.
Environment > context > global precedence is deterministic. Invalid appearance
sections retain their source file and working defaults; saves are disabled until
repair. Captured-context and competing-file checks prevent rebinding a save.
Runtime flags/environment overrides never become persisted settings.

The active `--invert` session option resolves named/ANSI defaults to explicit RGB,
reverses light/dark mode and repairs text/surface/accent contrast. Original
framework themes and stored palette definitions remain unchanged. About provides
original KubeRich version/license content with scrollable narrow-terminal access.

The release service is disabled by default. Explicit opt-in owns a bounded
three-second/64-KiB unauthenticated HTTP request and private 24-hour cache. PEP 440,
draft/prerelease/foreign-URL checks cannot invent a newer stable release on an
error. Local cache errors do not block startup, redirects are refused and no
credentials/cookies/inherited proxy settings are sent. About identifies cached
results. Owned cleanup survives repeated cancellation and child-before-parent
teardown; the checker never downloads or runs a package.
