# KubeRich 0.2.0

Customize the workspace and run local plugins. The
[changelog](../../CHANGELOG.md) lists the individual changes.

## Features

- Preview and save built-in or custom themes globally or per context ([#56](https://github.com/carloshm91/kuberich/issues/56)).
- Customize navigation keys, aliases and resource columns, with working defaults after invalid settings ([#57](https://github.com/carloshm91/kuberich/issues/57)).
- Check explicitly configured plugin files without running commands ([#58](https://github.com/carloshm91/kuberich/issues/58)).
- Confirm local plugins through typed forms; choose captured output, background jobs or a full terminal ([#59](https://github.com/carloshm91/kuberich/issues/59)).
- Consult compatibility notes, dependencies and alternatives for common K9s plugin files ([#60](https://github.com/carloshm91/kuberich/issues/60)).
- Inspect ConfigMap and Secret keys; reveal or copy values only when requested, with text/Base64 controls ([#55](https://github.com/carloshm91/kuberich/issues/55)).
- Edit Secrets through private drafts, redacted previews, server dry-run and separate Apply confirmation ([#55](https://github.com/carloshm91/kuberich/issues/55)).
- Recall commands and filters, use inverse/fuzzy filters and mark favorite namespaces ([#61](https://github.com/carloshm91/kuberich/issues/61)).
- Copy names or text through the clipboard and enable mouse reporting explicitly ([#61](https://github.com/carloshm91/kuberich/issues/61)).
- Forward named ports with presets, transport choices and optional reconnects ([#62](https://github.com/carloshm91/kuberich/issues/62)).
- Rename or delete kubeconfig contexts with a backup, and review completed or failed pods for `:cleanup` ([#63](https://github.com/carloshm91/kuberich/issues/63)).
- Define related-resource jumps and open them with `:jump` ([#64](https://github.com/carloshm91/kuberich/issues/64)).
- Reload preferences while running; invalid files keep the last working settings ([#64](https://github.com/carloshm91/kuberich/issues/64)).
- Set `read_only` and `refresh_seconds` per context, use the terminal background, show full API titles and see unknown-setting notices ([#64](https://github.com/carloshm91/kuberich/issues/64)).
- Install prebuilt Homebrew bottles on macOS Apple Silicon, macOS Intel and Linux x86_64 ([#193](https://github.com/carloshm91/kuberich/issues/193)).

## Fixes

- Release old table data when views change and size configuration-key columns correctly on their first paint ([#62](https://github.com/carloshm91/kuberich/issues/62)).
- Keep plugin file locations and working directories when migrating preferences ([#58](https://github.com/carloshm91/kuberich/issues/58)).
- Return to earlier themes without repeatedly parsing their styles ([#58](https://github.com/carloshm91/kuberich/issues/58)).
- Use updated aiohttp and certifi versions addressing published security advisories.

## Compatibility and migrations

- Python packages continue to use CPython 3.12–3.14 on Linux or macOS.
- Existing 0.1.0 preferences load unchanged, and new settings are optional.
- Preferences and kubeconfig change only when you save or confirm an edit.
- Homebrew bottles support macOS 14+ Apple Silicon, macOS 15+ Intel and Linux x86_64; other systems build from source.

## Installation

Choose one Python installer for this version:

```sh
uv tool install --python 3.12 kuberich==0.2.0
# Alternative:
pipx install --python python3.12 kuberich==0.2.0
```

For the current Homebrew tap version:

```sh
brew install kuberich/tap/kuberich
```

Use [0.2.0 downloads](https://github.com/carloshm91/kuberich/releases/tag/v0.2.0)
for four standalone platform archives, `DOWNLOAD-SHA256SUMS`, and dependency
and source reports.
See [Install](../installation.md) for checksums and installation choices.

## Upgrade and uninstall

- Upgrade from 0.1.0 with `uv tool upgrade kuberich`, `pipx upgrade kuberich` or `brew upgrade kuberich/tap/kuberich`.
- Replace an explicit version constraint deliberately to move beyond that version.
- Uninstall with `uv tool uninstall kuberich`, `pipx uninstall kuberich` or `brew uninstall kuberich/tap/kuberich`; preferences and kubeconfig stay intact.

## Known limits

- Plugins run only from files you configure; KubeRich does not download or update plugins.
- Real EKS, AKS and GKE cluster trials remain separate from local testing ([#87](https://github.com/carloshm91/kuberich/issues/87)).
- Mac archives use ad-hoc signatures and lack Developer ID notarization.
- Later releases cover remaining capabilities; this release does not claim complete K9s parity.
